# Fiddler 简介

## 什么是 Fiddler

Fiddler 是一款强大的 HTTP 调试代理工具，由 Telerik 公司开发。它能够捕获、分析和修改 HTTP/HTTPS 流量，是 Web 开发、测试和网络调试的必备工具。

## 主要功能

### 🌐 流量捕获

- 捕获所有 HTTP 和 HTTPS 请求和响应
- 支持移动设备、桌面应用和浏览器流量
- 实时显示网络通信详情

### 🔍 请求分析

- 查看完整的请求头、响应头和内容
- 支持多种格式（JSON、XML、HTML、图片等）
- 性能分析和时间统计

### ✏️ 请求修改

- 拦截并修改 HTTP 请求和响应
- 断点调试功能
- 自动响应和重定向

### 🔧 网络模拟

- 模拟不同的网络条件（慢速网络、离线等）
- 带宽限制和延迟设置
- 错误状态码模拟

### 🛡️ 安全测试

- HTTPS 解密和分析
- 认证和授权测试
- 安全漏洞检测

## 适用场景

### 前端开发

- 调试 API 接口调用
- 分析网络性能问题
- 模拟各种响应数据

### 后端开发

- 测试 RESTful API
- 分析 HTTP 协议细节
- 调试服务器响应

### 测试工程师

- 接口自动化测试
- 性能测试和分析
- 安全测试

### 网络管理员

- 网络故障排查
- 流量分析
- 协议分析

## 核心优势

### 🎯 易用性

- 直观的用户界面
- 丰富的可视化工具
- 详细的文档和社区支持

### 🔌 扩展性

- 支持自定义插件
- 脚本扩展功能
- API 接口

### 🚀 性能

- 高效的流量处理
- 低系统资源占用
- 快速的搜索和过滤

### 🌍 兼容性

- 支持 Windows、macOS、Linux
- 兼容所有主流浏览器
- 支持移动设备调试

## 版本说明

### Fiddler Classic

- 免费版本
- 基础功能完整
- Windows 平台专用

### Fiddler Everywhere

- 跨平台版本
- 现代化界面
- 部分高级功能需要付费

### Fiddler Cap

- 云端版本
- 团队协作功能
- 企业级支持
